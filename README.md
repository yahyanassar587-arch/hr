# بناء APK
1. أنشئ مستودع جديد على GitHub وارفع كل محتويات هذا المجلد (بما فيها مجلد .github).
2. افتح تبويب Actions ← Build APK ← انتظر 5-8 دقائق.
3. من صفحة التشغيل نزّل الملف payroll-apk (جواه app-debug.apk) وثبّته على الموبايل.
ملاحظة: النسخة Debug مناسبة للاستخدام الشخصي. الطباعة (window.print) لا تعمل داخل التطبيق؛ استخدم التصدير CSV.
